# Lawn Defense (Defensores do DOM)

Um jogo de Tower Defense inspirado no clássico Plants vs. Zombies, desenvolvido com HTML5, CSS3 e JavaScript puro.

## Descrição do Funcionamento

O **Lawn Defense** é um jogo de estratégia onde o objetivo é proteger sua base de hordas de zumbis famintos. O jogador deve posicionar diferentes tipos de plantas defensivas em um gramado dividido em trilhas para impedir o avanço dos inimigos.

### Mecânicas Principais:
*   **Gestão de Recursos:** Colete sóis que caem do céu ou que são produzidos por Girassóis para obter energia.
*   **Plantio Estratégico:** Utilize sua energia para posicionar defesas:
    *   **Girassol:** Gera energia extra ao longo do tempo.
    *   **Lançador de Ervilha:** Dispara projéteis contra os zumbis na mesma linha.
    *   **Noz-parede:** Atua como um escudo resistente para atrasar o progresso dos zumbis.
*   **Ondas de Inimigos:** Os zumbis surgem em ondas cada vez mais desafiadoras, com diferentes níveis de resistência e velocidade.
*   **Níveis de Dificuldade:** Escolha entre Fácil, Normal e Difícil para ajustar a intensidade do desafio.
*   **Persistência:** O jogo registra sua maior pontuação (onda sobrevivida) utilizando o armazenamento local do navegador.

## Instruções para Execução

Para rodar o jogo localmente, não é necessária nenhuma instalação complexa ou servidor robusto. Siga os passos abaixo:

1.  **Clonar ou baixar o repositório:** Certifique-se de ter todos os arquivos e pastas (`assets/`, `css/`, `js/`) preservados em sua estrutura original.
2.  **Abrir o arquivo principal:**
    *   Navegue até a pasta `game/`.
    *   Localize o arquivo `index.html`.
    *   Abra o `index.html` em qualquer navegador moderno (Chrome, Firefox, Edge, Safari).
3.  **Dica:** Para uma melhor experiência com os efeitos sonoros, recomenda-se usar um servidor local simples (como a extensão "Live Server" do VS Code) ou simplesmente garantir que as permissões de áudio do navegador estejam ativas.
